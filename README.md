# Mini Web Development Course

A beginner-friendly mini course teaching the basics of web development. Learn to create structured HTML pages, style them with CSS, add images and links, and test your knowledge with a simple quiz.

## Lessons
1. **Lesson 1 – HTML Basics**: Headings, paragraphs, and structure.
2. **Lesson 2 – CSS Basics**: Styling, colors, fonts, and spacing.
3. **Lesson 3 – Images & Links**: Adding images and hyperlinks.

## Quiz
- A short 3-question quiz to test your understanding.

## How to Access
- Open `index.html` in a browser to access all lessons and the quiz.
- Exercises are included in each lesson.

## Technologies
- HTML5
- CSS3
- JavaScript (quiz)
